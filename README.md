# Machine Learning Projects


- **House Prices (Regression):** House price prediction using Linear Regression, Ridge, Lasso, and Elastic Net.
- [Dataset](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data?select=train.csv)

  
- **Adult Income (Classification):** Predicting whether annual income exceeds $50K. A tuned Random Forest reached an F1 of 0.70 on the `>50K` class.
- [Dataset](https://www.kaggle.com/datasets/wenruliu/adult-income-dataset?resource=download)

  
- **Stroke Prediction (Boosting):** Predicting stroke occurrence. Only about 5% of patients had a stroke, so recall and F1 were tracked instead of accuracy. A tuned LightGBM reached an F1 of 0.27.
- [Dataset](https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset)

- **Credit Card Customer Segmentation (Unsupervised Learning):** Grouping credit card customers by spending behavior using PCA, K-Means, Hierarchical Clustering, DBSCAN, and HDBSCAN, and flagging unusual customers with Isolation Forest.
- [Dataset](https://www.kaggle.com/datasets/arjunbhasin2013/ccdata)
